# Card Atlas — generic source shell

Native SwiftUI iPhone source for browsing a card collection, storing local binder notes, OCR matching against supplied metadata, and experimenting with a manual tabletop.

The published catalog is intentionally empty. Publisher-derived data, catalog fetch/import tools, publisher-specific OCR fixtures and the original icon are excluded. Supply independently licensed card metadata in `App/Resources/cards.json` and original artwork before using catalog-dependent features. Core model and UI source remain for study and adaptation.

Generate the Xcode project with `xcodegen generate`, open `SteveJacksonGames.xcodeproj`, and configure your own signing team. Historical target/file names remain for source compatibility. See [PUBLICATION.md](PUBLICATION.md) for scope and missing resources. This export has not been build-validated.
