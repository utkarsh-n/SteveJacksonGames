# Publication content boundary

This repository is a generic Card Atlas source shell. The local prototype used Steve Jackson Games publisher checklists; those datasets, their importer, associated catalog fixture tests and the original icon are excluded from this public snapshot. The bundled `cards.json` is an empty array.

No publisher artwork, card scans, rulebook text, complete card abilities, or catalog metadata is supplied here. Historical source identifiers do not imply endorsement or a license. Use only data and artwork you have permission to redistribute. The source shell does not claim to be a complete implementation of any publisher's game.
